# Mathe-Spiele 9G

Kurze Lernspiele für den Mathematikunterricht in Jahrgang 9 (G-Kurs), Gustav-Heinemann-Gesamtschule Essen.

Jedes Spiel ist eine einzelne HTML-Datei und läuft im Browser, am Smartboard und auf dem iPad.

| Spiel | Thema |
|---|---|
| [Elfmeter-Cup](elfmeter-cup.html) | Watt, Kilowatt, Kilowattstunden, Stromkosten (Ergebnis eintippen) |
| [Strom-Profi](strom-profi.html) | Watt, Kilowatt, Kilowattstunden, Stromkosten |
| [Funktion oder nicht?](funktion-oder-nicht.html) | Senkrechtentest, Definitions- und Wertemenge |
| [Zahlenmaschine](zahlenmaschine.html) | Funktionsgleichung, Funktionswerte |

Spielarten: Klassenduell (Team Blau gegen Team Orange) und Blitzrunde. Drei Niveaus: Basis, Standard, Expert.
