Buch S. 66: Im Durchschnitt kommen pro Sekunde 2,6 Menschen hinzu.
Das sind pro Tag etwa 225 000 Menschen – so viele, wie in einer Großstadt wohnen.
Beispiel · Äthiopien (Buch S. 68)
Äthiopien hat 102 Mio. Einwohner.
Die Bevölkerung wächst jedes Jahr um 3 %.
Vermutung: Nach wie vielen Jahren leben dort doppelt so viele Menschen?
Denkfalle
„3 % von 102 Mio. sind 3,06 Mio. pro Jahr. Für 102 Mio. mehr braucht man also 102 : 3,06 ≈ 33 Jahre.“ – Stimmt das? Was wird dabei übersehen?
Einstellungen
Wachstumsfaktor
exponentiell (· q pro Jahr) linear (+ gleich viel pro Jahr)
JahrRechnungEinwohner (Mio.)
Denk nach
Stelle p auf einen negativen Wert. Was passiert mit dem Graphen? Wie groß ist dann q?
Merke · Wachstumsfaktor
Wächst eine Größe jedes Jahr um p %, so multipliziert man jedes Jahr mit dem Wachstumsfaktor
q = 1 + p100
Zunahme 2 %: q = 1,02  ·  Zunahme 3 %: q = 1,03
Abnahme 0,6 %: q = 0,994
Merke · nach x Jahren
Startwert k, Wachstumsfaktor q:
f(x) = k · qx
Ghana: f(x) = 28 · 1,02x
2020 (x = 4): 28 · 1,024 ≈ 30,3 Mio.
Die Variable x steht im Exponenten → Exponentialfunktion.
Achtung · Typischer Fehler
28 · 1,024 ≠ (28 · 1,02)4  – zuerst die Potenz, dann mal k!     Und: 3 % ≠ 1,3 – der Faktor ist 1,03.
